# 🗺️ Vietnam Travel Map 2026

Интерактивная карта Вьетнама для планирования длительного путешествия (3 месяца осенью 2026).

## Идея проекта

Создать веб-приложение — дашборд с интерактивной картой Вьетнама, где можно:
- Изучать города, достопримечательности, пляжи, аэропорты и порты с двуязычными подписями (русский + вьетнамский).
- Смотреть фото мест и переходить к галереям.
- Получать прогноз погоды на 7 дней по любой точке.
- Делать личные заметки к городам и местам.
- Планировать маршруты: наземные, перелёты, реальные прибрежные круизы и информационные карточки международных круизов (без фейковых линий через материк).
- Фильтровать слои и переключать виды карты.

## Технологический стек

- **HTML5 / CSS3 / JavaScript** — без фреймворков для простоты и скорости.
- **Leaflet.js** — интерактивные карты.
- **CartoDB Voyager / OpenStreetMap / Esri Satellite** — подложки карты.
- **Open-Meteo API** — бесплатная погода без API-ключа.
- **Unsplash** — фото в попапах.
- **localStorage** — хранение заметок, пользовательских маршрутов, трат, дат поездки/визы и курса валют.
- **Open Exchange Rates API** — бесплатный курс рубля к вьетнамским донгам (VND/RUB) для конвертации трат.
- **GitHub Pages** — бесплатный хостинг (опционально).

## Логика разработки

### 1. Данные (`js/data.js`)

Все точки хранятся в объекте `VIETNAM_DATA`. Каждая точка имеет:
- `id` — уникальный идентификатор.
- `name` — русское название.
- `nameViet` — вьетнамское название в скобках.
- `type` — тип: `city`, `attraction`, `beach`, `airport`, `port`.
- Маршруты (`routes`) поддерживают `type`: `road`, `flight`, `cruise`, `info`. Для круизов можно задать `path` — массив координат, идущих по воде.
- `region` — регион для погодных советов: `north`, `central`, `central_coast`, `south`, `highlands`.
- `coords` — координаты `[lat, lng]`.
- `description` — краткое описание.
- `images` — массив URL фото (1–3 штуки).
- `gallery` — ссылка на поиск фото Google.

### 2. Карта (`js/map.js`)

- Инициализируется Leaflet с центром на Вьетнам.
- Создаются маркеры по типам.
- Добавляются попапы с фото, описанием и кнопками.
- Рисуются линии маршрутов. Круизы с `path` следуют по заданным водным точкам; информационные (`info`) маршруты не рисуются на карте.
- Работают переключатели слоёв.

### 3. Погода (`js/weather.js`)

- Загружается текущая температура для списка городов.
- По клику открывается детальный прогноз на 7 дней.
- Показываются советы по сезону для региона.

### 4. Заметки (`js/notes.js`)

- Сохраняются в `localStorage`.
- Можно экспортировать/импортировать JSON.
- Есть поиск по заметкам.

### 5. Маршруты (`js/routes.js`)

- Предустановленные маршруты из `VIETNAM_DATA.routes`.
- Пользовательские маршруты сохраняются в `localStorage`.
- Кнопка "На карте" центрирует и подсвечивает маршрут.

### 6. Траты и бюджет (`js/expenses.js`)

- Общий бюджет поездки (по умолчанию $6000 на двоих за 3 месяца).
- Форма добавления трат с категориями: еда, жильё, транспорт, перелёты, развлечения, шопинг, медицина, визы, другое.
- Прогресс-бар заполнения бюджета на дашборде и на странице трат.
- История трат, статистика, график распределения по категориям.
- Экспорт/импорт трат в JSON.

## Как добавить новую точку

1. Откройте `js/data.js`.
2. Найдите нужный массив (`cities`, `attractions`, `beaches`, `transport`, `routes`).
3. Добавьте объект с обязательными полями:

```javascript
{
    id: "my-place",
    name: "Моё место",
    nameViet: "Tiếng Việt",
    type: "attraction",
    region: "north",
    coords: [21.0, 105.8],
    description: "Описание места.",
    images: ["https://images.unsplash.com/photo-..."],
    gallery: "https://www.google.com/search?tbm=isch&q=..."
}
```

4. Перезагрузите страницу — точка появится на карте автоматически.

## Тестирование

### Что проверить

1. Карта загружается и центрирована на Вьетнам.
2. Все слои маркеров включаются/выключаются.
3. Попапы открываются по клику.
4. Погода загружается и показывает прогноз на 7 дней.
5. Заметки сохраняются после перезагрузки страницы.
6. Маршруты рисуются на карте.
7. Траты сохраняются, бюджетный прогресс-бар обновляется.
8. Дашборд переключается между вкладками.

### Известные ограничения прототипа

- Фото загружаются с Unsplash по прямым ссылкам — иногда могут дублироваться.
- Для добавления новых точек нужно редактировать `data.js` вручную.
- Пользовательские маршруты — прямые линии между точками (в т.ч. через правый клик на карте), без реального построения по дорогам.
- Международные круизы отображаются карточками без линий, чтобы не показывать фейковые прямые через сушу.
- Границы Вьетнама подгружаются из внешнего GeoJSON — требуется интернет.
- Погода берётся по ближайшим координатам Open-Meteo.
