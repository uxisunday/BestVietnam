# 🗺️ VoyageMap (bestvn) — план поездки во Вьетнам 2026

**Это единственная актуальная версия сайта.** Старый прототип `vietnam-map/` удалён —
все правки вносить только сюда.

Интерактивный дашборд для планирования длительного путешествия (3 месяца осенью 2026):
карта Вьетнама, личные заметки, планировщик, учёт трат, погода, маршруты.

## Структура проекта

```
bestvn/
├── index.html          # Главный HTML-файл с дашбордом

│   ├── weather.js      # Погода Open-Meteo API

└── README.md           # Этот файл
```

## Технологический стек

- **HTML5 / CSS3 / JavaScript** — без фреймворков.
- **Leaflet.js** — интерактивные карты; векторный базовый слой **OpenFreeMap (стиль Liberty)**
  через MapLibre GL Leaflet, запасные — Esri (топография/спутник + оверлей подписей);
  слой заведений — **Overpass API** (данные OpenStreetMap, без ключа).
- **Open-Meteo API** — погода без ключа; **Open Exchange Rates** — курс VND/RUB.
- **Cloudflare Worker + D1** — облачная синхронизация заметок/трат по JWT-логину
  (`https://bestvi.bestvietnam-sync-morning.workers.dev`).
- **GitHub Pages** — хостинг: `https://uxisunday.github.io/BestVietnam/`
  (репозиторий `uxisunday/BestVietnam`).

## Дизайн-система (актуальная, «тёплое стекло»)

Задана CSS-переменными в `css/style.css` → `:root`:
- Палитра: светло-бежевый фон `#f5f1e8`, тёмно-зелёный текст `#1f2d26`, акцент-изумруд `#1b7a57`.
- Шрифтовая пара: **Manrope** (интерфейс/текст) + **Lora** (заголовки h1–h3, названия заметок) через Google Fonts.
- Стекломорфизм: `backdrop-filter: blur()` у сайдбара, карточки логина и панели карты.
- Подсказки-плейсхолдеры заметно светлее основного текста; иконки смягчены под палитру
  (никаких розово-красных плашек и фиолетовых плюсов).

### Мобильный слой (актуальный)

- Брейкпоинты: **900px** (структурный: нижняя навигация, натуральный скролл, 1 колонка),
  **480px** (полиш: типографика, тач-таргеты, шиты), **375px** (плотность), `(pointer: coarse)` (поведение).
- Навигация ≤900: нижняя панель с 5 вкладками (Dashboard, Map, Routes, Notes, Траты) +
  шит «Ещё» (Weather, Планнер, Settings). На десктопе сайдбар как прежде.
- Тач-таргеты ≥44px у всех кнопок/чипов/строк списков; основные кнопки — на всю ширину.
- Типографика ≤480: h1 26px, метки не мельче 12px, карточки 16px, `.tab`-padding 16px.
- Все инпуты ≤900 — 16px (отключает авто-зум Safari); safe-area-inset учтён в нижнем баре,
  шитах и sticky-элементах; шелл на `100dvh`.
- Конструктор маршрута на карте ≤480 — нижний шит; создание метки — полноэкранный шит;
  чипы фильтров/слоёв — горизонтальные скролл-ленты.
- Грид-элементы мобильных layout'ов имеют `min-width: 0` — иначе nowrap-ленты растягивают
  колонки до ширины контента и всё обрезается справа.
- Погода ≤900: длинный список городов скрыт, вместо него селект (Ханой выбран по умолчанию),
  подробный прогноз сразу под ним; на десктопе список как прежде.
- Траты/бюджет: `window.appData.expenses` — единый источник для дашборда и вкладки «Траты»;
  пустое облако не затирает локальные траты — они дотягиваются в облако при чтении.

## Обновления от 30.08.2026

- Дизайн переделан в «тёплую современную» тему: беж + изумруд, матовое стекло, единые зелёные кнопки
  (высоты 40/42px), все плюсики — обычным символом «+» (эмодзи ➕ красился в фиолетовый на Windows).
- Типографика: пара Manrope + Lora; заголовки serif, подсказки легче основного текста.
- Редактор заметки перестроен: крупное поле «Текст заметки» (минимум 340px) — главный элемент;
  теги и адрес — компактные поля в две колонки; выбор «Метка на карте» свёрнут в `<details>`
  внизу формы (само разворачивается, если заметке назначена точка).
- Теги: чипсы с удалением + выпадающий список уже существующих тегов (`datalist`).
- Город: автоподстановка **латиницей** (`hanoi`, `halong`, …) из `VIETNAM_DATA`;
  исправлен глобально сломанный доступ `window.VIETNAM_DATA` (top-level `const` не попадает в window).
- Категории/теги/города-фильтры: теги сверху, список городов свёрнут в «▸ 📍 Города»;
  при открытом редакторе панель фильтров и саббар скрываются целиком.
- Ширина: на больших экранах контент ограничен 1360px и центрирован (как у Ozon/Notion),
  кроме полноэкранной карты — поля больше не растягиваются «на вероятные длины».
- Автозаполнение Chrome убрано надёжно: `autocomplete="off"` + поля «readonly до первого клика»
  (Chrome игнорирует autocomplete=off). Синяя заливка автозаполненных полей перекрашена в фон темы,
  строка поиска дополнительно автопочищается (0.1/0.6/2 c).
- Траты: приглушённая палитра категорий; компактные полосы статистики (подпись и проценты
  вынесены за дорожку), карточки трат приведены к общей теме.
- Красные/розовые «плашки» (пины, popup, напоминания планировщика, баннер) — заменены
  на изумрудные и нейтральные тона; корзина удаления — нейтральная, краснеет только на hover.
- Фикс бага тегов: старые теги заметки удалялись при добавлении нового (чипсы без `data-tag`).
- Карта полностью переделана (плотность POI «как в Google»):
  - базовый слой — векторный **OpenFreeMap «Liberty»** (бесплатно, без ключа и водяных знаков),
    рендер через MapLibre GL внутри Leaflet (все маркеры/маршруты сайта продолжают работать);
  - новый слой **«🏪 Заведения»** — кафе, рестораны, магазины, аптеки, банкоматы, отели, музеи,
    АЗС… подтягиваются из OpenStreetMap через Overpass API для текущей области экрана,
    до 400 точек; с зума 15 и меньше — только цветные значки, с зума 16 — чипы с названиями,
    по клику — карточка с адресом, часами работы, телефоном и сайтом;
  - запасные слои: Топография (Esri) и Спутник (Esri) + оверлей «Подписи городов»;
  - CartoDB отдавал водяные знаки «API KEY REQUIRED», растровый OSM блокировался (403),
    векторные тайлы решают обе проблемы и дают чёткий зум на любом увеличении.
- Ключ OpenRouteService теперь реально читается из настроек
  (раньше читали localStorage, куда он не сохранялся, поэтому маршрут всегда строил OSRM).
- Дашборд: карточки времени (Вьетнам / Москва) схлопнуты в одну компактную;
  добавлены **календарь** месяца (стрелки листают месяцы, период поездки подсвечен зелёным,
  сегодня — залитая плашка) и **курсы валют** (1 $ в ₽ и ₫, 10 000 ₫ в ₽, 1 ₽ в ₫) —
  обновление раз в сутки с суточным кэшем (open.er-api.com, без ключа).
- data.js: заменены два умерших фото Unsplash (круизы Халон→Гонконг, Хошимин→Пномпень).

## Логика работы

### Заметки (`js/notes.js`)
- Модель: `{id, title, body, category, subcategory, tags[], city(id), cityName, address, coords, pinType, images[], updatedAt}`.
- Категории по умолчанию (медицина, жильё, транспорт, еда, шопинг, развлечения…) +
  пользовательские категории/подкатегории (синхронизируются).
- Каждая заметка сохраняется в облако при нажатии «Сохранить»; поиск — по названию,
  тексту, адресу, тегам и городу.

### Траты (`js/expenses.js`)
- Модель: `{id, category, amount (VND), desc, date}`; бюджет в рублях, категории с цветами,
  статистика по категориям, экспорт/импорт.

### Карта (`js/map.js`)
- Полноэкранная вкладка; клик «📍 На карте» в редакторе заметки выбирает точку на карте.
- Режимы слоёв, предустановленные маршруты (`VIETNAM_DATA.routes`), круизы — карточками без
  фейковых линий через сушу.
